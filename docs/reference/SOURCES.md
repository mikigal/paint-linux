# Windows 11 Paint – reference screenshots

Third-party screenshots of the real Microsoft Paint for Windows 11, collected on 2026-10-27 for
local visual comparison only (this folder is gitignored – do not commit or redistribute).
Copyright belongs to Microsoft and the respective publishers.

Notes:
- Paint versions: 11.21xx (2021 redesign, Clipboard group, no Edit menu) → 11.2304 (dark mode, Settings page)
  → 11.2308 (layers, Edit menu, Clipboard group gone) → 11.2402 (side size slider replaces the "Size" group,
  layer Background tile) → 11.2412 (Copilot menu replaces Image Creator/Cocreator buttons) → 11.2504 (Object
  select, Stickers) → 11.2508 (opacity slider, project files) → 11.2512 (fill tolerance) → 11.2601 (freeform rotate). Prefer the 2025–2026 images for the toolbar layout; older ones are kept for
  menus/dialogs that have not changed much.
- Files converted from GIF animations are a single representative frame (frame index noted in the description).
- "crop" = cut out of the linked full image by me; nothing was otherwise edited.
- `main-window-light-01.png` and `main-window-light-02.png` are 1:1 at 100 % scaling and are the best sources
  for pixel measurements; `main-window-light-03.png` is ~260 % and best for icon shapes.
